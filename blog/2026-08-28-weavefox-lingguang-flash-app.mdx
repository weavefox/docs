前不久，灵光正式开放了闪应用生态——支持一键部署 Skill 接入，意味着 Codex、Claude Code 等第三方 AI 工具也能直接创建和发布灵光闪应用，「一句话生成 AI 应用」不再局限于灵光 App 内。

现在，WeaveFox 作为首批接入的平台，灵光闪应用 Agent 正式上线了。

{/* truncate */}

## 接入灵光 Agent 意味着什么？

灵光的生态围墙，打开了。

不是灵光给 WeaveFox 开了个入口这么简单，而是灵光把闪应用的生成、预览、发布能力，变成了任何 AI Agent 都能调用的开放能力。WeaveFox 是第一个接入的平台，但不会是最后一个。

过去，AI Agent 之间各干各的——你在 Codex 里写应用，在灵光里做闪应用，在 WeaveFox 里做网页应用。现在灵光把这堵墙拆了：你在 WeaveFox 里做出来的闪应用，能直接发布到灵光平台；未来在任何 AI 工具里做出来的应用，也都能进入灵光生态。

做出来的闪应用还能一键转发到灵光圈——被使用、评论、点赞、二次创作。不用自己找流量，作品像内容一样被发现和传播，一个解决极小问题的工具，也能找到真正需要它的人。

我们想打通 AI Agent 之间的墙壁，让创造力自由流动起来。

## 怎么用？

只需要三步：

1. 打开 WeaveFox 平台，在个人中心绑定灵光 APP 的 token
2. 在首页会话时选择「灵光闪应用」Agent 类型，描述你想要的闪应用，比如"帮我做一个贪吃蛇游戏"
3. 预览 → 调整 → 发布，不满意继续对话优化，满意后一键发布到灵光平台

## 小提示

灵光闪应用 Agent 目前处于测试阶段，能力还在逐步完善中：目前**仅支持生成静态应用**，暂不支持需要动态数据接口、实时联动的复杂应用。

也正因为是测试阶段，你的反馈格外重要。无论体验好不好、哪里不好用、希望支持什么能力，都欢迎随时告诉我们，帮助我们把灵光闪应用 Agent 打磨得更好。

## 立即体验

现在就打开 WeaveFox 平台，选择灵光闪应用 Agent，开始你的第一次闪应用 Vibe Coding 之旅吧～
