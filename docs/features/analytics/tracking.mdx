# 数据分析

WeaveFox 为每个应用提供内置的数据分析能力，帮助你了解用户如何使用你的应用。

## 访问数据分析

进入应用创作页面后，点击左侧导航栏的**分析**标签页，即可查看应用的数据概览。

## 默认采集的数据

应用发布后，系统会自动采集以下用户行为数据，无需任何配置：

| 指标             | 说明                        |
| ---------------- | --------------------------- |
| PV（页面浏览量） | 页面被访问的总次数          |
| UV（独立访客数） | 访问页面的独立用户数        |
| 操作系统         | 用户使用的操作系统分布      |
| 设备类型         | 桌面端、移动端、平板等分布  |
| 浏览器           | Chrome、Safari、Edge 等分布 |
| 语言             | 用户浏览器语言分布          |
| 来源域名         | 用户从哪个网站跳转而来      |

这些数据以图表形式展示，包括 30 天访问趋势、各维度占比分布等。
