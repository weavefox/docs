# 规划模式

规划模式是 WeaveFox 提供的任务拆解与逐步执行功能。当你有较为复杂的需求时，可以启用规划模式，让 AI 帮你将任务拆分为多个可执行的子任务，然后逐步完成。

## 启用方式

在聊天输入框中，点击 **「规划」** 按钮即可启用规划模式。

## 功能特点

### 任务拆解

启用规划模式后，AI 会先分析你的需求，将复杂的任务拆分为多个子任务，并为每个子任务生成具体的执行计划。

### 待办清单

在输入框上方显示待办清单 (Todo List)，包含：

- **任务标题**：每个子任务的名称
- **任务描述**：该任务的具体执行步骤
- **执行状态**：进行中 / 已完成 / 已取消

## 使用场景

- **复杂功能开发**：需要多个步骤才能完成的功能
- **系统重构**：涉及多个文件的修改
- **批量任务**：需要按顺序执行的多项操作
- **新功能规划**：不确定如何开始，需要 AI 给出实施建议

## 注意事项

- 规划模式适用于较复杂的任务，简单任务无需启用
- 规划模式相较于常规模式耗时可能较长，但会获得更好的任务完成质量
- 在不主动启用规划模式的情况下，WeaveFox 会视任务复杂度自动判断是否进入规划模式，如果不想使用该模式，请在提示词中描述不使用规划模式
