# 技能

创建技能，为 WeaveFox 定义可重用的按需工作流。打包重点明确的说明文档、操作手册和清单，在遇到匹配的任务时告诉 WeaveFox 使用技能来构建应用功能。

技能让你教 WeaveFox 如何处理重复性任务。告诉 WeaveFox 一次你想怎么做，每次遇到类似任务时它都会应用同样的工作流程。

技能是简短的、命名的操作手册，每个技能都有一个名称、一个告诉 WeaveFox 何时使用该技能的描述，以及一个包含 WeaveFox 在使用该技能时应遵循的指令文档说明。

## 技能的用途

技能最适合用于特定任务的工作流程，你希望 WeaveFox 每次都以相同的方式重复执行这些流程。常见用途包括：

- 设计风格定义
- 周期性内容任务（版本说明、变更日志、客服支持回复、营销文案）
- 通用业务流程的需求文档（登录功能设计、计费逻辑、管理权限设计）
- 专业知识文档（特定领域知识、三方服务集成说明）

:::tip[创建技能]

推荐积极探索应用创作过程中的一些重复性任务场景，总结并创建技能，借助技能提高构建应用的准确性与效率。

:::

## 创建技能

要创建技能，请按照以下操作步骤：

- 进入工作台页面，导航到**技能页面**
- 点击右上角**创建技能**按钮，进入编辑页面
- 更新 SKILL.md 文件的名称与描述信息，完善文档内容
- 设置**技能权限**，选择是否公开给其他人使用
- 点击右上角**创建按钮**，进入审核状态
- **审核通过**后，技能将可以被正常使用

:::note[上传压缩包]

如果你是专业用户，或者你准备创建的技能拥有大量引用的文档，你可以在本地编辑好后通过编辑器左上角上传按钮，一次性将所有文件上传到编辑器中，支持 ZIP 压缩包上传。

:::

## 使用技能

目前，使用技能是用户的主动行为，由创作者判断任务场景，并主动激活特定技能。

在应用创作过程中，如果遇到特定任务场景，你可以通过点击对话框左下角的**扩展按钮**，在弹窗中选择技能标签页下的任何一个技能，告诉 WeaveFox 按照技能文档的流程完成该任务。

你可以通过搜索关键字来找到匹配任务场景的技能，默认只展示公开的技能列表，点击搜索框右侧『我的』按钮切换为你个人创建的所有技能列表（包含公开与私有）。

:::warning[自动激活技能]

未来，WeaveFox 将会根据任务场景，主动搜索可用的技能并激活使用。但在创作过程中，你主动选择激活特定技能仍然是推荐且最优的选择。

:::

## 剖析技能

每个技能包含三个**必备**部分：

- **名称**：一个简短的标识符。
- **描述**：用一句话告诉 WeaveFox 解决了什么问题，何时应该使用此技能。
- **指令**：技能正文部分，以 Markdown 格式编写，具体描述该技能解决问题、完成任务的工作流程。

一个好的实践经验是，把 WeaveFox 当作第一次执行该任务的新队友，写下你会给的一些指示：做什么、避免什么、需要注意的极端情况以及你期望的反馈格式。

`SKILL.md` 文件是必须的，另外技能还可以包含引用文件，你可以将一个复杂任务场景的工作流程拆分的更细，或者应对不同情况时编写不同的工作流程文档。

一份清晰的技能描述是技能最重要的部分。如果描述含糊不清，WeaveFox 可能不会按预期使用该技能，或者将其加载到不相关的任务中。好的描述会明确定义技能的适用场景和不适用场景。清晰的界限有助于 WeaveFox 始终如一地加载正确的技能，避免将其误用到无关的任务中。

### 好与坏技能描述对比

WeaveFox 会根据技能描述来决定何时加载技能。描述模糊和描述精确之间的差别会对技能运行的可靠性产生重大影响。

**太模糊**

```
description: 对 SEO 优化有帮助。
```

这段描述并没有清楚地告诉 WeaveFox 何时使用该技能、它适用于哪种 SEO 任务，或者它实际应该做什么。

**具体且有范围**

```
description: 用于审核现有页面的 SEO 健康状况：检查元数据、标题结构和内部链接。不适用于从头开始编写新的 SEO 文案。
```

这份描述提到了：

- 触发器（审计现有页面）
- 范围（元数据、标题、内部链接）
- 以及边界（不用于撰写新文案）

描述得当，可以使技能加载更加一致，并减少相似技能之间的冲突。

## 常见问题

- **技能必须要审核后才能使用吗？**

  必须。考虑到内容安全风险，技能的创建与编辑都需要审核流程，且审核通过后才可用。不过，你不必担心，只要内容合规，审核通常很快（几分钟）。
