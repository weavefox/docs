# 版本管理

WeaveFox 会为应用创作过程中的每一次对话后涉及到应用文件变更的生成一个版本快照。你可以查看历史版本、预览任意版本的效果，以及回滚到之前的版本。

## 版本是如何产生的

在应用创作过程中，每次 WeaveFox 助手回复并生成应用内容时，系统会自动创建一个新版本。版本按创建顺序依次编号（v1、v2、v3……），每个版本对应一次完整的对话产出。如果你只是简单的询问问题，没有涉及到应用的代码文件变更，则不会产生新的版本。

## 查看历史版本

点击应用聊天创作页面右上角的 **「历史版本」** 按钮，即可打开版本面板，查看当前应用的所有版本记录。

版本面板中每个版本条目包含：

- **版本缩略图**：该版本应用的预览截图
- **版本名称**：如 v1、v2 等
- **创建时间**：该版本的生成时间
- **已发布标记**：如果该版本是当前已发布的版本，会显示「已发布版本」标记

此外，在对话消息中，每条助手消息下方也会显示 **「版本 N」** 标记，作为快捷方式点击即可快速跳转并查看对应版本。

## 回滚版本

当你对当前版本不满意，想回到之前的某个版本时，可以使用回滚功能。

在历史版本面板或对话助理消息下方的版本标记旁，点击 **回滚按钮** ，确认后即可回滚到该版本。

:::warning[回滚不可逆]

回滚操作会删除目标版本之后的所有版本及其对应的对话记录，此操作不可撤销，请谨慎使用。

:::

## 发布与版本

发布应用时，系统会基于当前选中的版本生成快照并部署。已发布的版本不受后续修改影响——在你发布新版本之前，线上应用始终展示的是已发布版本的内容。

**另外，已发布的版本回滚后也不会影响线上应用，只是你再也无法找到已发布的版本记录。**

更多发布相关内容，请查看[发布应用](/features/deploy-host/publish-app)。
