# 应用创作

通过**自然语言对话**的方式，将你的想法与灵感，快速构建为真实的产品应用。

你需要关注的是如何准确描述出你的想法，例如：

- 更具体的提示词
- 多段文本描述
- 参考图
- 参考文档
- ...

WeaveFox 会理解你提供的所有提示信息，总结并生成计划，最终构建一个 Web 应用。

接下来：

- 了解[技能](./skills)，使用外部知识库为 WeaveFox 提供实现特定功能的最佳实践
- 了解[规划模式](./plan-mode)，在复杂场景下让 WeaveFox 拆解任务，逐步完成
- 了解[版本管理](./version-management)，查看历史版本、预览与回滚应用版本

了解更多创作方式，请查看[最佳实践](/best-practices/overview)。
