# 应用协作

邀请其他用户参与应用创作，分配权限，实时观察你们共同构建的变动。

WeaveFox 让你们一起构建应用，邀请你的产品经理、设计师、运营、开发者或其他任何人，每个人都能实时看到变化发生。

协作者有两种权限：

- **只读**：可以查看应用的聊天记录、源代码、版本记录、应用配置等数据数据。
- **读写**：除过只读的所有权限，还可以参与到对话创作中，编辑应用配置信息等等。

:::note[协作者]

协作者不能发布和删除应用。

:::

## 如何添加协作者

要添加应用协作者，你需要按照以下步骤操作：

1. 打开应用的聊天页面，点击右上角的**添加协作者按钮**。
2. 调整**协作权限**，默认为只读
3. 点击**复制邀请链接按钮**，发送给被邀请的用户
4. 受邀请的用户点击链接地址打开页面，并点击**同意**加入协作

:::warning[注意]

邀请链接有过期时间，过期后链接将会失效，可以重新点击复制邀请链接按钮生成新的链接。

:::

## 管理协作者

你可以在应用的聊天页面，点击右上角添加协作者按钮，查看参与协作的用户列表，并**调整指定用户的协作权限，包括移除协作权限**。
