# 自定义域名

为了让你的应用更具个性化和专业性，WeaveFox 支持为每个应用配置**自定义域名**。

默认生成的应用标识不具备较强的可读性，推荐为你的应用配置能体现其特点的自定义域名，这可以提升你的应用的：

- **品牌形象**：看起来更值得信赖和专业
- **搜索引擎友好**：更好的 SEO 和可发现性
- **易记性**：用户更易分享和记忆

## 如何配置自定义域名

要为你的应用配置自定义域名，可以通过以下几种方式：

- 在应用设置页面，找到**个性化域名**选项进行编辑配置。
- 在应用聊天页面，点击右上角**发布按钮**后出现的弹层中进行编辑。

:::warning[注意]

自定义域名通常不会有特殊的限制，但需要**具备唯一性**，因为这是访问应用的 URL 链接中的唯一标识。

:::
