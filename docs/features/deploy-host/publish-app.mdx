# 发布你的应用

将应用部署到一个可实时访问的 URL 网址，控制谁可以访问已发布的应用，并随时更新版本。

发布通过将你的 WeaveFox 应用的**特定版本快照**部署到你可以分享的一个 URL 网址，将其变为一个可实时访问的 Web 应用。一次只部署一个版本，你可以根据需要控制应用的访问权限。

:::tip[预览与发布]

WeaveFox 使用两种模式控制应用的访问：

- **预览模式**：这是你在应用对话创作过程中进行应用预览的模式，包括源代码、聊天记录、版本历史以及任何其它有关应用的数据信息，你可以通过邀请协作者参与到应用创作。
- **应用发布**：这是你构建好的应用通过发布上线来分享给你的用户的方式，通过权限限制可以访问你的应用的用户。

这两种模式的访问权限是相互独立的。

:::

## 谁可以发布应用？

默认情况下，只有应用的**创建者**具备删除应用的权限。拥有**读写**权限的协作者也可以发布应用。

:::note[协作者]

拥有**读写**权限的协作者可以发布应用，协作者不能删除应用。

:::

## 应用的访问权限

你可以根据需要调整发布的应用的访问权限，目前支持以下几种模式：

- **私有**：仅应用的创建者可以访问
- **公开**：所有的用户都可以访问

:::warning[指定用户访问]

指定用户访问的权限控制正在开发中...

:::

## 如何发布你的应用

发布应用，请按照以下操作步骤：

1. 进入应用的聊天页面，点击右上角的**发布按钮**，将会展示应用的 URL 地址，权限情况，以及正在发布的版本。
2. 为你的应用设置**个性化域名**。
3. 配置网站**访问权限**。
4. 审查**安全问题**，确认以上配置正确，并且应用已经准备好，数据库权限符合预期，没有泄露服务密钥等敏感信息。
5. **发布**你的应用。

发布后，你可以随时更新并重新发布你的应用，更改域名地址（发布 URL），打造优秀的产品用户体验。

## WeaveFox 中的发布流程

每次发布时，WeaveFox 都会将你的应用快照部署到一个实时网址，且只部署当前指定版本，未来的更改不会自动发布。

- 聊天页面编辑后的应用版本不会自动发布。
- 要部署更改，请重新点击**发布按钮**。

如果你在网站上没有看到最近的更改，你应该需要重新发布。

## 如何撤销发布的应用

目前，已发布的应用不支持撤销发布，但你可以将其立即**设置为私有权限**，其他用户将不能再访问你的应用，即便他们知道你的应用 URL 地址。

## 常见问题

- **发布会泄露我的应用的源代码吗？**

  不会。发布只会让应用在已发布的 URL 上可访问，它不会让任何人访问你的应用聊天页面或项目代码。

- **未发布的应用可以被访问吗？**

  不会。从未发布过的应用，任何人通过 URL 访问都会返回 404 页面，提示应用不存在。

- **已发布的应用被删除了还能被访问吗？**

  不会。通过 URL 只能访问已经发布且未被删除的应用，其它情况都会返回 404 页面，提示应用不存在。
