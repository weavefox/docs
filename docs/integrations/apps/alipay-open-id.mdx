# 支付宝一键登录

WeaveFox 生成的 H5 应用可以快速接入支付宝生态，实现**支付宝一键登录**。根据你的需求，有两种方案可选：

|  | 支付宝 H5 应用 | 支付宝小程序 |
| --- | --- | --- |
| **适用账号** | 个人 / 企业均可 | 仅企业账号 |
| **接入方式** | 独立 H5 页面 | WebView 嵌入小程序 |
| **登录能力** | ✅ 支付宝快捷登录 | ✅ 支付宝快捷登录 |
| **适用场景** | 独立传播、分享裂变 | 支付宝生态内分发 |

> 💡 如果你的应用**仅在支付宝内打开、不需要支付宝登录**，则无需配置以下任何内容。

![拾光地图支付宝登录示例](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785464193890-4852ef10-e96b-411c-9896-b852b313a5c7.png)

_拾光地图 — 支付宝快捷登录效果示意_

## 方案一：支付宝 H5 应用

> 适合独立传播的 H5 页面，个人账号和企业账号均可使用。

### 第一步：注册支付宝 H5 应用

1. 登录 [支付宝开放平台](https://open.alipay.com/develop/manage)
2. 点击「创建网页/移动应用」

![创建网页/移动应用](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785461753740-af8ff40e-e79d-4203-b701-dac014239976.png)

_点击「创建网页/移动应用」按钮_

3. 填写应用信息（网址 URL 可暂不填），点击立即创建

![填写应用信息](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785461832529-0af4da34-d254-46b9-808c-5d19ede53e26.png)

_填写应用名称、图标、简介等基本信息_

### 第二步：配置密钥

1. 进入应用设置页，点击「开发设置」→「接口加签方式」→「设置」

![开发设置页面](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785462836438-120221d1-38b3-43c9-9a0c-a69e783fc8e9.png)

_进入应用详情 → 开发设置_

2. 加签方式选择「密钥」，点击下一步

![选择加签方式](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785462851486-778ef373-9797-4e5b-a846-9bdd0dbc7893.png)

_选择「密钥（普遍适用）」_

3. 下载密钥工具，生成 RSA2 密钥对，复制「应用公钥」

![生成密钥](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785462884403-2e58f8c4-a70c-4648-89dd-106e220dd2d8.png)

_使用密钥工具生成 RSA2 密钥对_

4. 将「应用公钥」粘贴到开放平台，点击确认上传

![上传公钥](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785462896815-c990f0d1-64a9-4b52-9e2c-6397d39d6ebe.png)

_粘贴应用公钥字符串_

5. 保存好密钥文件中的「应用私钥」（支付宝不会保存，丢失需重新生成）

![密钥工具保存](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785463020700-cee4606c-fd04-4163-a477-fd25e9303598.png)

_妥善保存应用私钥，丢失无法找回_

### 第三步：WeaveFox 生成应用

在 WeaveFox 中创建并发布你的 H5 应用，获得应用域名。

### 第四步：设置授权回调地址

1. 回到开放平台 → 开发设置 →「授权回调地址」→「设置」

![授权回调地址入口](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785463474683-fbe8c54a-e11d-4870-86c8-69aa53a682fd.png)

_点击「授权回调地址」旁的「设置」_

2. 填写你的 WeaveFox 应用域名（回调地址类型选 HTTPS）

![填写回调地址](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785463444774-3036c162-6a92-4503-9344-1de5b3e7a745.png)

_填入 WeaveFox 发布后的应用域名_

### 第五步：WeaveFox 平台配置 Token

打开 [WeaveFox 支付宝登录配置页](https://www.weavefox.cn/vault/services/alipay-open-id)，填写以下三项：

| 配置项 | 说明 | 获取位置 |
| --- | --- | --- |
| **App ID** | 应用唯一标识 | 开放平台 → 应用详情页 |
| **支付宝公钥** | 用于验签 | 开放平台 → 接口加签方式 → 查看 |
| **应用私钥** | 用于签名 | 密钥工具生成的私钥文件 |

![WeaveFox 配置页面](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785463978853-022c7536-8fc5-4273-ad3f-7414e063727d.png)

_在 WeaveFox 平台填入三项配置即可完成接入_

## 方案二：支付宝小程序

> 通过 WebView 嵌入 WeaveFox H5 应用，实现小程序内调用支付宝能力。**仅企业账号可用。**

### 第一步：注册小程序应用

1. 登录 [支付宝开放平台](https://open.alipay.com/develop/manage)
2. 点击「创建小程序」

![创建小程序](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785463541062-1ab0139c-2958-49a9-afa5-1376ca03cc3a.png)

_选择「小程序」类型创建_

### 第二步：配置密钥

小程序配置密钥的步骤和 H5 应用**完全一致**，参考方案一中「第二步：配置密钥」。

![小程序开发设置](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785463693439-78293989-1ad4-494a-94bf-d414d8d37bc2.png)

_小程序同样需要在开发设置中配置接口加签方式_

### 第三步：配置域名白名单

:::warning[重要]
域名白名单仅企业支付宝账号才能配置，因此个人开发者无法使用小程序嵌入 H5。
:::

1. 进入小程序 → 开发设置 →「服务器域名白名单」→「添加」
2. 填入你的 WeaveFox 应用域名（如 `footprint.app.weavefox.cn`）

![域名白名单](https://intranetproxy.alipay.com/skylark/lark/0/2026/png/111765/1785463742419-b0577d21-16e9-4095-938c-aa9e2861efc0.png)

_将 WeaveFox 域名添加至服务器域名白名单_

其他配置（授权回调地址、Token）与方案一中的步骤一致，参考方案一第四步和第五步。

### 第四步：WeaveFox 平台配置 Token

与方案一第五步完全一致，在 [WeaveFox 支付宝登录配置页](https://www.weavefox.cn/vault/services/alipay-open-id) 填入 App ID、支付宝公钥和应用私钥即可。

---

## 配置完成 ✅

以上两种方案任选其一即可。配置完成后，你的 WeaveFox 应用就能在支付宝内实现一键登录，用户无需额外注册即可使用。

> 💡 **小结**：个人开发者选「方案一：支付宝 H5 应用」；企业开发者如有小程序分发需求，可用「方案二」将 H5 嵌入小程序。
