# 支付宝 OpenID 服务

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

支持 **H5** 和 **支付宝小程序** 授权登录，通过 authcode 获取用户 OpenID 并绑定应用。

## 使用场景

- **H5 授权登录**：在 Web 应用中集成支付宝 OAuth 授权
- **小程序身份绑定**：在支付宝小程序中获取用户唯一标识 OpenID
- **多应用管理**：支持配置多个支付宝应用密钥，灵活切换

## 如何使用

在对话中说：应用集成支付宝登录服务

## 配置说明

需要在支付宝开放平台创建应用，获取：

- **App ID**：应用唯一标识
- **支付宝公钥**：用于验签
- **应用私钥**：用于签名
