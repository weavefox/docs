# 地图服务

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

集成高德地图 LBS 开放平台提供丰富的位置服务能力。

## 功能特性

- **地理编码**：地址转换为经纬度坐标
- **逆地理编码**：经纬度坐标转换为地址
- **POI 搜索**：关键字搜索和周边搜索地点
- **路径规划**：驾车、步行、骑行、公交路线规划
- **行政区域**：省市区行政区划查询
- **天气查询**：城市实时天气和天气预报
- **输入提示**：地址输入自动补全

## 使用场景

- 附近商家/餐厅查找应用
- 导航路线规划应用
- 位置签到/打卡应用
- 天气查询应用
- 地址智能补全功能

## 如何使用

在对话中说：「帮我创建一个附近餐厅查找应用」或「创建一个天气查询应用」，系统会自动集成高德地图能力。
