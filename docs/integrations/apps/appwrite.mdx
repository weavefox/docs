# AppBase

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

OceanBase 提供的后端服务，支持数据库存储、用户认证等能力。

## 功能特性

- **数据库**：提供关系型数据库存储服务
- **用户认证**：支持基于角色的权限管理认证服务

## 使用场景

- 数据持久化
- 登录鉴权
