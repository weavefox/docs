# 音频识别服务

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

基于多模态模型的音频理解能力，支持多种音频处理场景。

## 功能特性

- **语音转文字**：将音频内容转录为文字稿
- **音频理解推理**：分析音频内容并回答问题
- **情感识别**：识别语气、情感等副语言信息
- **语音对话理解**：理解对话内容和主题

## 使用场景

- 会议记录自动生成
- 采访内容整理
- 语音笔记数字化
- 播客内容摘要
- 情感分析与客服质检

## 如何使用

在对话中说：「帮我使用音频识别服务创建一个语言转文字应用」，系统会自动集成音频识别能力。
