# 内容搜索

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

智能内容搜索服务，支持全文检索和语义搜索。

## 功能特性

- **全文检索**：高效的关键词搜索
- **语义搜索**：基于语义理解的相关性搜索
- **向量检索**：支持向量相似度搜索
- **混合检索**：关键词 + 语义混合搜索

## 使用场景

- 文档搜索
- 知识库检索
- 商品搜索
- 内容推荐
