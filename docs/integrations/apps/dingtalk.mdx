# 钉钉消息推送

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

通过钉钉机器人 webhook 发送消息到钉钉群，支持文本、Markdown、卡片等多种消息类型。

## 使用场景

- **运维告警**：系统异常时自动推送告警
- **任务通知**：任务完成、失败时发送状态通知
- **数据报表**：定时推送数据统计报表

## 如何使用

在对话中说：「帮我使用钉钉消息推送服务创建一个运维告警通知应用」，系统会自动集成钉钉推送能力。
