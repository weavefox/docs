# 邮件服务

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

为应用提供邮件发送能力，支持 HTML 富文本邮件。

## 功能特性

- **通知邮件**：订单确认、系统通知、状态变更提醒
- **联系表单**：网站反馈表单、用户咨询表单提交后发送邮件
- **验证码邮件**：注册/登录验证码、密码重置链接
- **报告邮件**：定时数据报表、任务执行结果
- **HTML 富文本**：支持完整 HTML 格式正文，灵活排版

## 使用场景

- 电商订单确认与发货通知
- 用户注册/登录验证码
- 网站联系表单/反馈表单
- 定时数据报表推送
- 系统告警与异常通知

## 如何使用

在对话中说：「帮我使用邮件服务创建一个联系表单应用」，系统会自动集成邮件发送能力。

## 注意事项

- 邮件服务为内置服务，默认发送方邮箱为 `service@mail.weavefox.cn`，无需用户单独配置 SMTP
- 每月有调用配额限制，可在「用量」标签页查看
- 邮件内容会经过安全校验，请勿发送垃圾/违规内容
