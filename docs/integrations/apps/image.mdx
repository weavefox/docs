# 图像生成与编辑服务

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

基于多模态模型的图像生成与编辑能力，支持文生图和图像编辑两种模式。

## 功能特性

- **文生图**：根据文本描述生成图片
- **图像编辑**：基于参考图片进行编辑
- **换背景**：更换图片背景，保持主体不变
- **换材质**：更换物体材质，保持形状和光影
- **角色一致性**：保持角色特征，改变场景或动作

## 支持的场景

- **快速图片生成**：快速产出大量图片，适合电商营销海报、商品主图、快速创意验证
- **高品质图片生成**：高保真人像与风景，精准捕捉微观纹理，适合复杂中文意境
- **换背景/换材质**：商品图场景替换，保持光影和特征不变

## 使用场景

- 电商海报与商品主图生成
- 艺术质感图像创作
- 图像编辑与修图
- 角色/IP 一致性创作

## 如何使用

在对话中说：「帮我使用图像生成服务创建一个电商海报生成应用」，系统会自动集成图像生成能力。
