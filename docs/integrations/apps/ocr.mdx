# OCR 识别服务

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

基于多模态模型的光学字符识别能力，支持多种文字识别场景。

## 功能特性

- **通用文字识别**：识别图片中的所有文字内容
- **表格识别**：提取表格内容并转换为 Markdown 格式
- **发票/票据识别**：结构化提取发票信息
- **证件识别**：识别身份证、银行卡等证件信息
- **文档解析**：长文档内容提取
- **手写文字识别**：识别手写体文字
- **数学公式识别**：将数学公式转换为 LaTeX 格式
- **GUI 元素识别**：识别界面元素和布局

## 使用场景

- 文档数字化与归档
- 发票报销自动化
- 表格数据提取
- 证件信息自动填写
- 手写笔记数字化
- 数学公式编辑辅助

## 如何使用

在对话中说：「帮我使用 OCR 识别服务创建动物识别应用」，系统会自动集成 OCR 识别能力。
