# 内容安全检测

:::note[WeaveFox 云]
WeaveFox 平台云服务
:::

平台内置的内容安全服务，支持在发布、展示或存储用户内容前进行安全校验。

## 功能特性

- **文本检测**：审核评论、帖子、昵称、简介等文本内容
- **图片检测**：审核用户上传图片或公网图片 URL
- **图文检测**：一次提交文本和多张图片进行组合检测
- **服务端代理**：平台凭证不会暴露到生成的应用中

## 使用场景

- 社区帖子与评论发布前审核
- 用户头像、封面和作品图片审核
- 表单自由输入内容校验
- AI 生成内容发布前复检

## 如何使用

在对话中说：「为这个应用接入内容安全检测，用户发布文本或图片前必须校验」，系统会自动生成客户端并完成接入。
