# 用户行为埋点

:::note[WeaveFox 云]
WeaveFox 平台云服务。
:::

为 Vibe Coding 生成的应用提供用户行为埋点能力，采集自定义事件，并在分析页面呈现和分析用户行为数据。

所有 WeaveFox 生成的应用自动具备埋点能力，无需手动开启或配置。默认采集以下用户行为信息：

| 指标             | 说明                        |
| ---------------- | --------------------------- |
| PV（页面浏览量） | 页面被访问的总次数          |
| UV（独立访客数） | 访问页面的独立用户数        |
| 操作系统         | 用户使用的操作系统分布      |
| 设备类型         | 桌面端、移动端、平板等分布  |
| 浏览器           | Chrome、Safari、Edge 等分布 |
| 语言             | 用户浏览器语言分布          |
| 来源域名         | 用户从哪个网站跳转而来      |

## 自定义事件采集

除了默认数据，你还可以采集特定的业务事件，如按钮点击、表单提交、订单完成等。

### 如何使用

在应用创作页面，点击对话框左下角**扩展**按钮，在服务列表中选择**用户行为埋点**服务。然后，直接在对话中告诉 WeaveFox：

> 帮我的应用添加用户行为埋点，采集注册按钮点击和下单成功的事件

WeaveFox 会自动在代码中集成埋点逻辑。

## 查看自定义事件

启用自定义事件采集后，采集到的事件数据会展示在分析页面的**自定义事件**区域，你可以查看每个事件的触发次数和占比。
