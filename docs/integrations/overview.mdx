# WeaveFox 集成服务

将 WeaveFox 连接到外部工具和外部服务 APIs。

**WeaveFox 的集成服务**功能可让你将应用程序连接到外部工具、APIs ，使用真实数据作为上下文并安全地集成第三方服务以实现功能。

:::tip[应用服务]

使用 WeaveFox，可以为你的应用集成：

- 数据库
- 用户认证
- 文件存储
- AI 服务（多模态识别与生成）
- 消息推送
- ...

:::

## 应用服务

应用服务是扩展 WeaveFox 生成应用的功能的最简单方法。它们就像插件一样，你的应用可以在需要执行操作或获取数据时随时调用它们。

当你**发布的应用需要与外部服务交互**以获得运行能力时，应用服务是理想之选。

### 主要特点

应用服务在用户级别进行授权管理，可在应用之间提供可重用的程序功能。

- 在工作台的**服务页面**进行管理
- 只需配置一次
- 提供你的应用在使用过程中可以调用的功能

### 授权管理

WeaveFox 平台提供了一些内置云服务，这些默认启用且无需授权。

另外，WeaveFox 也接入了部分三方服务，这些需要进行授权配置后才可以启用。请按照以下操作步骤：

1. 进入工作台的**服务页面**
2. 找到你需要的**服务**卡片
3. 点击服务卡片进入详情页，查看信息，并根据说明进行**授权配置**
4. **授权配置成功**后服务将在你的应用中可用

### 使用服务

如果要为你的应用添加服务以实现特定功能，请在输入提示时，点击对话框左下角的**扩展按钮**，选择你要接入的服务，WeaveFox 会根据你的要求在实现应用功能时集成该服务能力。

### 查看服务状态

你可以在应用的**云服务页面**查看哪些服务已经启用，及其服务的具体状态信息。例如：

- 数据库实例的信息（有哪些表、表权限、表数据）
- 用户信息（当前应用的注册用户列表）
- AI 服务使用量
- ...

### 现有服务列表

#### 数据库

- [AppBase](/integrations/apps/appwrite) - OceanBase BaaS 服务，提供数据库存储、用户登录认证等后端能力
- [Supabase](/integrations/apps/supabase) - 三方数据存储方案，连接 Supabase 数据库，实现数据持久化存储和实时同步功能

#### 存储

- [OSS 存储](/integrations/apps/oss) - 静态资源存储服务，支持图片、音视频及各类文件上传，单文件最大 100MB

#### AI 服务

- [LLM 服务](/integrations/apps/llm) - 提供大语言模型调用能力，支持文本生成、对话等 AI 功能
- [图像生成](/integrations/apps/image) - 支持文生图、图像编辑、换背景、换材质、角色一致性创作等多种图像生成场景
- [音频识别](/integrations/apps/audio) - 支持语音转文字、音频理解、情感识别等多种音频处理场景
- [OCR 识别](/integrations/apps/ocr) - 支持图片文字识别、表格提取、发票识别、证件识别等多种 OCR 场景
- [内容安全检测](/integrations/apps/security-check) - 为应用提供文本、图片及图文组合的内容安全检测能力

#### 搜索服务

- [内容搜索](/integrations/apps/content-search) - 语义搜索、内容检索能力

#### 消息推送

- [钉钉消息推送](/integrations/apps/dingtalk) - 钉钉群消息推送服务，通过钉钉机器人 webhook 发送消息到钉钉群
- [邮件服务](/integrations/apps/email) - 为应用提供邮件发送能力，支持通知邮件、报告邮件、联系表单、验证码邮件等场景

#### 地图

- [高德地图服务](/integrations/apps/amap) - 提供地图定位、地理编码、POI 搜索、路径规划等位置服务能力

#### 数据分析

- [用户行为埋点](/integrations/apps/tracking) - 为 Vibe Coding 生成的应用提供用户行为埋点能力，采集自定义事件，并呈现和分析用户行为数据

#### 登录认证

- [支付宝 H5 应用登录](/integrations/apps/alipay-open-id) - 面向在支付宝 App 内打开的 H5 应用，实现支付宝一键登录

#### 支付服务

- [支付宝支付](/integrations/apps/alipay-payment) - 支持创建支付订单、查询交易状态、退款、关闭订单等支付宝支付能力
- [Vibe Pay](/integrations/apps/vibe-pay) - 创建并上架线上电子商品，绑定商家支付宝实现收款
