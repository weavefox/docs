# WeaveFox 集成服务

将 WeaveFox 连接到外部工具和外部服务 APIs。

**WeaveFox 的集成服务**功能可让你将应用程序连接到外部工具、APIs ，使用真实数据作为上下文并安全地集成第三方服务以实现功能。

:::tip[应用服务]

使用 WeaveFox，可以为你的应用集成：

- 数据库
- 用户认证
- 文件存储
- AI 服务（多模态识别与生成）
- 消息推送
- ...

:::

## 应用服务

应用服务是扩展 WeaveFox 生成应用的功能的最简单方法。它们就像插件一样，你的应用可以在需要执行操作或获取数据时随时调用它们。

当你**发布的应用需要与外部服务交互**以获得运行能力时，应用服务是理想之选。

### 主要特点

应用服务在用户级别进行授权管理，可在应用之间提供可重用的程序功能。

- 在工作台的**服务页面**进行管理
- 只需配置一次
- 提供你的应用在使用过程中可以调用的功能

### 授权管理

WeaveFox 平台提供了一些内置云服务，这些默认启用且无需授权。

另外，WeaveFox 也接入了部分三方服务，这些需要进行授权配置后才可以启用。请按照以下操作步骤：

1. 进入工作台的**服务页面**
2. 找到你需要的**服务**卡片
3. 点击服务卡片进入详情页，查看信息，并根据说明进行**授权配置**
4. **授权配置成功**后服务将在你的应用中可用

### 使用服务

如果要为你的应用添加服务以实现特定功能，请在输入提示时，点击对话框左下角的**扩展按钮**，选择你要接入的服务，WeaveFox 会根据你的要求在实现应用功能时集成该服务能力。

### 查看服务状态

你可以在应用的**云服务页面**查看哪些服务已经启用，及其服务的具体状态信息。例如：

- 数据库实例的信息（有哪些表、表权限、表数据）
- 用户信息（当前应用的注册用户列表）
- AI 服务使用量
- ...

### 现有服务列表

#### 数据库

- [AppBase](/integrations/apps/appwrite) - BaaS 平台，提供数据库、认证、存储、实时订阅等
- [Supabase](/integrations/apps/supabase) - 开源 Firebase 替代方案，提供 PostgreSQL 数据库、认证、存储等

#### 存储

- [OSS 存储](/integrations/apps/oss) - 阿里云对象存储服务，用于文件存储和 CDN 分发

#### AI 服务

- [LLM 服务](/integrations/apps/llm) - 大语言模型服务，支持多种模型接入
- [图像生成与编辑服务](/integrations/apps/image) - AI 图像生成和编辑能力
- [音频识别服务](/integrations/apps/audio) - 语音转文字、音频处理能力
- [OCR 识别服务](/integrations/apps/ocr) - 文字识别、文档扫描能力

#### 搜索服务

- [内容搜索](/integrations/apps/content-search) - 语义搜索、内容检索能力

#### 消息推送

- [钉钉消息推送](/integrations/apps/dingtalk) - 钉钉群机器人消息推送
- [邮件推送](/integrations/apps/email) - 邮件发送服务

#### 地图

- [地图服务](/integrations/apps/amap) - 高德地图服务，支持定位、导航等功能

#### 登录认证

- [支付宝 OpenID 服务](/integrations/apps/alipay-open-id) - 支付宝快捷登录能力

#### 支付服务

- [支付宝电脑网站支付](/integrations/apps/alipay-payment) - 支付宝 PC 端网页支付能力
