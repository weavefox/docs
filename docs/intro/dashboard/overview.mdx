# 工作台概览

学习如何使用 WeaveFox 的工作台，创建新应用、编辑个人资料、创建技能以及授权服务。

![WeaveFox 工作台](https://mdn.alipayobjects.com/huamei_4qpv3u/afts/img/fRL_RrcRX-4AAAAAgCAAAAgAeocTAQFr/fmt.webp)

## 创建新应用

在**应用页面**的对话框中输入你想构建的内容描述，然后点击发送以创建新应用。

了解更多信息，请查看[快速开始](../getting-started/quick-start)。

### 输入提示

在对话框输入你的想法，或点击麦克风按钮，使用语音输入并口述你的想法。

WeaveFox 将根据你的描述生成一个应用。你可以根据需要进行简明扼要或详尽的描述，例如，**一个待办事项应用，支持主题切换**，或者一个包含多段文字的详细说明。

:::info[最佳实践]

了解更多信息，请查看[最佳实践](/best-practices/overview)。

:::

### 上传附件

点击对话框左下角的**附件按钮**，你可以上传受支持的文件类型，例如图片、PDF 文档等等。

WeaveFox 会理解你上传的附件内容，并结合你输入的描述生成一个应用。

### 添加扩展技能

点击对话框左下角的**扩展按钮**，你可以选择添加一个服务或者技能来增强你的应用功能。

WeaveFox 会激活指定的技能文档和工具，生成比静态页面具备更加丰富能力的全栈应用。

:::tip[使用扩展]

通常，推荐使用扩展来增强生成应用的能力。

:::

## 侧边栏与导航

### 应用

在应用页面你可以查看和管理**你创建的应用以及你参与协作的应用**，通过应用卡片进入应用创作页面、设置页面、公开分享页面。

### 个人主页

个人主页主页展示你的**个人资料**，包括用户名、用户 ID、个性签名，包括你的一些社交数据（粉丝数量、关注用户数量、应用获赞数量），其中点击粉丝、关注可以查看具体的用户列表数据。用户名旁边的编辑按钮可以进入个人资料编辑页面，你可以在其中修改你的用户名、用户 ID、个性签名、头像等信息。

同时，该页面也会展示你的个人**创作足迹日历**，统计数据来源于你在 WeaveFox 的一些创作行为和社交行为，例如创建应用、公开应用、创建技能、关注其他用户等等。

你设置为**公开的所有应用**作品会展示在该页面的下方。

:::tip[个人主页]

个人主页是公开的，任何人都可以访问查看你的个人主页和你公开的应用作品，其它用户可以关注你，也能为你公开的应用作品点赞收藏。

:::

### 点赞收藏

该页面会展示你**点赞收藏**过的所有公开应用作品的列表。

### 发现

在发现页面你可以查看 **WeaveFox 实时推荐的热门创作者与应用作品**，探索其它用户的创作，获取灵感。

### 技能

在技能页面你可以查看和管理**你创建的技能**，通过技能卡片进入技能详情页面，进行编辑或者设置公开状态。

:::info[技能]

了解更多信息，请查看[技能](/features/build/skills)。

:::

### 服务

在服务页面你可以查看 WeaveFox 集成的所有服务，并管理**你授权的三方服务**，通过服务卡片进入服务详情页面，查看服务的详细信息，或者管理授权信息。

:::info[集成服务]

了解更多信息，请查看[集成服务](/integrations/overview)。

:::

## 消息通知

点击你头像旁边的**消息通知按钮**，你可以查看 WeaveFox 的系统消息和通知，例如其它用户关注了你、点赞收藏了你公开的应用，你的应用公开、技能公开审核通知等等。
