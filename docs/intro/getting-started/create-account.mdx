# 创建账户

创建你的 WeaveFox 账户，即可开始**使用自然语言构建和迭代全栈 Web 应用程序**。

WeaveFox 账户是你在平台上的个人身份，用于登录、管理个人资料与偏好、以及访问工作台中的创作应用。无论你参与多少应用创作，只需要一个账户。

任何人都可以**免费注册**。注册后，WeaveFox 会自动为你创建个人工作台，你可以立即开始创作。

## 在 weavefox.cn 注册

访问 [www.weavefox.cn](https://www.weavefox.cn)，点击**开始创作**，选择以下任一方式注册：

- **手机号** — 输入手机号并通过短信验证码完成注册
- **支付宝** — 使用支付宝账号授权登录，并完成首次手机号绑定即可注册成功

:::tip

注册完成后，点击**开始创作**或者你的**个人头像**即可进入工作台。

:::

## 工作台

**工作台**是你的创作空间，保存你的应用和资源，你使用一个账户登录，在该账户下管理你的所有创作内容。你可以：

- **应用** — 查看你创建的应用以及你参与协作的应用
- **个人主页** — 管理你的个人资料，查看你的粉丝列表、关注列表，以及创作足迹日历与公开的应用列表
- **点赞收藏** — 查看你点赞过的他人公开应用的列表
- **技能** — 创建你的技能，为创作的应用提供更丰富的能力
- **服务** — 查看 WeaveFox 支持的集成服务，并授权管理三方服务

## 常见问题

### 收不到验证码怎么办？

- 检查手机短信是否被拦截或归入垃圾短信
- 确认输入的手机号格式正确
- 等待 60 秒后重新获取验证码
- 如持续无法收到，请加入用户群进行反馈

## 接下来

账户创建完成后，你可以：

- 创建你的第一个应用，体验应用生成能力
- 完善个人资料，在**工作台-个人主页**页面设置头像、昵称、社交媒体 ID 和个人简介
- 了解更多创作方式，浏览[最佳实践](/best-practices/overview)
