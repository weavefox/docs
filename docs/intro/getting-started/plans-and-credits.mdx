# 套餐与额度

WeaveFox 目前**没有付费计划**，应用创作完全免费。你可以自由使用平台的所有创作能力，无需担心额度限制。

## 集成服务额度

WeaveFox 提供的部分集成服务设有**月度免费额度**，帮助创作者实现更多创意创作，而无需额外付费。

月度额度在每月初自动重置，未使用的额度不会累积到下月。

:::info

关于集成服务的具体额度与用量，请参阅[集成服务](/integrations/overview)。

:::

## 常见问题

- **创作应用有数量限制吗？**

  当前用户创作的应用数量没有任何限制，但我们禁止对产品功能的滥用行为。
