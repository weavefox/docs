# 快速开始

创建你的第一个应用，通过对话的方式添加后端功能，并发布你的应用。

:::info[创作指南]

这份文档将指导你使用 WeaveFox 从零开始创建一个全栈应用，包含登录功能与云端数据库存储。

:::

## WeaveFox 产品概述

<details>
  <summary>创建你的第一个应用</summary>

- 第一步

  请前往 [**www.weavefox.cn**](https://www.weavefox.cn) 创建账户。

- 第二步

  只需输入一个初始提示来启动，WeaveFox 会帮你完成剩下的任务！这是《WeaveFox》中任何创作任务的起点，你可以**瞬间将创意与想法变为现实**。

</details>

<details>
  <summary>WeaveFox 工作台</summary>

在 WeaveFox 中，简单是关键：

- 在[**这里**](https://www.weavefox.cn/vault)，你只需一个提示即可启动你的项目。
- 从[**发现页**](https://www.weavefox.cn/discover)探索所有项目，包括最新和热门应用。
- 通过查看和编辑你的**个人主页**资料，个性化你的体验。

</details>

<details>
  <summary>应用概述</summary>

在 WeaveFox 中，每个应用的创作任务都遵循结构化工作流程：

- 使用基于聊天的界面**轻松编辑**。
- **附上图片**以便精准编辑和灵感理解。
- 通过**版本历史**跟踪变更，并恢复到任何之前的版本。
- 启用 **WeaveFox 云服务**实现后端功能。
- **发布、部署并通过链接分享**你的项目（记得更改后重新发布）。
- 在**网页视图和移动视图之间切换**，实现响应式设计。
- **预览模式**可以立即查看更新。

</details>

<details>
  <summary>应用设置</summary>

每个应用的设置都赋予你以下能力：

- **查看应用的关键细节**，如对话编辑次数和创建日期。
- 根据需要**调整项目访问权限**。
- 随时**更改应用名称、描述与标签**。
- **删除你的应用**（⚠️ 危险操作）。

</details>

## 开始创作你的应用

根据你的需求，有以下几种方式可以开始使用 WeaveFox 进行创作：

<details>
  <summary>提示词</summary>

直接通过自然语言对话的方式开始。

- 只需要在聊天框中描述你想构建什么。
- 越具体，效果越好。
- 从描述清晰且详细的提示开始。
- 你可以边做边细化和调整应用。

</details>

<details>
  <summary>使用草图</summary>

有时候，视觉表达比文字更有效。你可以通过上传草图来指导 WeaveFox 理解你的设计意图。

- 第一步

  使用其它绘图工具绘制你的 UI。

- 第二步

  将你绘制的 UI 进行截图，通过粘贴或者上传图片附件的方式添加到对话框，然后编写提示并发送。WeaveFox 会根据你的草图 UI 布局实现为真实的 Web 应用。

</details>

<details>
  <summary>复刻网站或者其它应用</summary>

- 第一步

  使用截图工具获取你想要复刻的网站或者其它应用的界面截图。

- 第二步

  通过粘贴或者上传图片附件的方式添加到对话框，然后编写提示并发送。

</details>

## 编辑你的应用

<details>
  <summary>提示词</summary>

直接通过自然语言对话的方式对应用进行编辑调整。

</details>

<details>
  <summary>在对话中添加图片</summary>

直接在聊天中附上图片，为提示词增添上下文。这使得更容易说明那些 UI 相关而非功能描述的观点或概念。

</details>

## 为你的应用添加全栈能力

<details>
  <summary>连接后端</summary>

如果你需要为应用添加后端功能，你可以：

- 连接 **WeaveFox 内置的 Appwrite BaaS**，在提示词中提及需要实现云端存储能力，WeaveFox 会自动识别并集成 Appwrite 云服务。
- 自己申请 Supabase 账户，并**在 WeaveFox 服务页面进行授权**。

</details>

<details>
  <summary>集成 AI 服务</summary>

如果你需要为应用添加 AI 服务能力，**WeaveFox 已经开箱即用的集成了常见的多种服务能力**。

- 提示词中直接描述你需要的 AI 服务，例如 OCR、LLM 等等，WeaveFox 会自动识别并集成对应的服务。

</details>

## 部署并发布你的应用

<details>
  <summary>设置自定义域名</summary>

你可以为你的应用设置个性化、语义化的域名，提升用户体验和品牌形象。你可以通过以下几种方式配置：

- 在应用设置中，找到**个性化域名**选项进行编辑配置。
- 在应用聊天页面，点击右上角**发布按钮**后出现的弹层中进行编辑。

更多信息请查看[自定义域名](/features/deploy-host/custom-domain)。

</details>

<details>
  <summary>发布应用</summary>

应用准备好后，发布后会生成可分享的 URL 链接。这使你可以轻松展示应用或与合作者和利益相关者分享。

更多信息请查看[发布应用](/features/deploy-host/publish-app)。

</details>
